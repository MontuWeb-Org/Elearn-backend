Overview

End-to-End User Flow

Four linked account tiers — Instructor, TA, Parent, Student — sharing one curriculum and schedule.

How to use this document

  1. Use the left rail to open any of the 24 screens, grouped by Authentication, Instructor Dashboard, TA Portal, Parent Portal and Student Portal.
  2. Each screen is a low-fidelity layout wireframe — structure and interaction only, not final visual design.
  3. Instructor and TA screens are framed as a web dashboard (multi-class management on a larger screen); Parent is framed as a mobile app per the "mobile-friendly, zero technical effort" goal; Student is framed as a web app to accommodate live video and quiz-taking.
  4. Yellow note panels under each screen describe interactions, edge cases and how the four roles connect.
Authentication

01 · Login

Single entry point for all four roles — role is resolved server-side and routes accordingly.

Teaching independently? Start as an instructor

Interactions & states

  1. Role routing: Instructor → 06; TA → 14; Parent → 17; Student → 19.
  2. A parent with multiple linked children logs in once and switches between them from Parent Home (17) — no separate login per child.
  3. Only instructors see the sign-up link; TA, parent and student accounts are always created via an instructor-issued invite (screens 04–05).
